# 奇迹狄芳环游大周｜换装小游戏

这是一个纯静态网页，不需要服务器或数据库，可直接部署到 GitHub Pages。

## 使用方法

1. 新建一个 GitHub 仓库。
2. 将本压缩包内的全部文件上传到仓库根目录。
3. 打开仓库的 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，点击 `Save`。
6. 等待 GitHub 生成访问网址。

## 当前控制逻辑

- 左边人物衣服：五件互斥，可恢复为不穿衣服。
- 右边人物衣服：四件互斥，可恢复为不穿衣服。
- 左边人物帽子：两款互斥。
- 右边人物帽子：一款独立开关。
- 链子刀、幽兰剑：两个独立开关，可同时显示。
- 背景：固定纯白。
