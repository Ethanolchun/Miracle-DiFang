# 奇迹狄芳环游大周

静态换装网页，可直接部署到 GitHub Pages。

## 本版本优化

- 李元芳与狄仁杰姓名已写入界面。
- 图片由透明 PNG 转为透明 WebP，缩小网页加载体积。
- 所有图层预加载并完成解码后统一显示，避免逐层或逐段出现。
- 使用 Service Worker 缓存资源，第二次及后续访问更快。
- 链子刀与幽兰剑互斥显示。

## 上传方法

将本压缩包解压后，把 `index.html`、`style.css`、`script.js`、`sw.js`、`images` 文件夹和本文件上传到仓库根目录。


## 保存搭配图片

点击网页衣橱顶部的“保存图片”，会将当前可见服装、帽子和配件按图层合成为一张 2048×2048 的白底 PNG，并自动保存到设备。
